# Quantum AI Desktop

**Quantum AI Desktop** is a high-fidelity interface for interacting with the first pre-trained Quantum Transformer model (**QT-4Q**). This tool allows researchers and developers to run local inference, visualize quantum attention states, and monitor model confidence in real-time.

---

## Technical Status

The **Quantum Transformer Core Library** used by this application is fully open-source and available here:
👉 [GitHub: quantum-transformer](https://github.com/reach-Harishapc/quantum-transformer)

### Internal Research & Source Code
The source code for this specific Desktop Interface is currently **private** (Closed Source) as it contains experimental internal research features and visualization tools. 
*   **Why?** To maintain stability during the research phase and protect proprietary visualization algorithms.
*   **Future**: We are fully committed to open-sourcing the frontend code once it reaches a stable production milestone.

---

## Getting Started

You can download the latest pre-built binaries for Windows and macOS from the [Releases](https://github.com/reach-Harishapc/quantum-ai/releases) section.

### Features
- **Local Inference**: Run the QT-4Q model entirely on your local hardware.
- **Quantum State Visualization**: Real-time monitoring of rotation gates and entanglement layers.
- **Shannon Entropy Guards**: Visualize the model's confidence levels as it generates text.
- **HF Integration**: Automatically download the latest weights from the Hugging Face Hub.
