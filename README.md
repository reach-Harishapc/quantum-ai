# Quantum AI - Desktop UI

This repository contains the professional web-based interface for the **Quantum Transformer (QT-4Q)**. It is built using FastAPI and Jinja2, designed to provide a high-fidelity environment for quantum-inspired AI research.

---

## Getting Started (Run from Source)

Since this is now open-source, you can run the UI directly on your machine:

### 1. Clone the repository
```bash
git clone https://github.com/reach-Harishapc/quantum-ai.git
cd quantum_ai
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the application
```bash
python main.py
```
The application will start at **http://127.0.0.1:8000**.

---

## Features
- **Real-time Inference Visualization**: Monitor quantum rotation gates and state probabilities.
- **Shannon Entropy Guards**: Visualize model confidence levels.
- **Hugging Face Integration**: Automatically pull pretrained weights from `Harishapc01/quantum-qt-4q`.
- **Local Training**: Interface for fine-tuning the model on your own datasets.
